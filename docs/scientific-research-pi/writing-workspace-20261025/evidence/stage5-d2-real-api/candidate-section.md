现有固定证据仅含两篇研究的摘要，允许在各自报告范围内讨论检索与事实性的关系。Lewis等报告，结合维基百科稠密索引的RAG较纯参数生成基线更具事实性；Asai等则指出，忽视必要性和相关性的固定检索可能产生无帮助回答，并报告按需检索与反思相结合的Self-RAG相对其指定基线改善了长文本事实性及引用准确性。这些摘要提示，检索内容及其使用方式值得共同考察，但尚不足以确立两篇研究之间可直接比较的事实性改善幅度。[1] [2]

<!-- claim:revision_limits_2 -->
两篇摘要报告的比较对象不同，固定证据又缺少事实性评估细节、效应量、误差及控制实验，因此不能据此判断Self-RAG优于Lewis等的RAG，也不能分离检索与自我反思的独立贡献，或推断检索在所有场景均有效、能够消除事实错误。本节仅作摘要层面的定性对照；指标与实验条件的可比性仍需取得全文核验，独立贡献和结论的适用范围还需相应控制实验及后续实证检验。[1] [2]
