## Why

2026-11-17 当前补充：讨论确认后已实施同效果从零重做、独立知识开关、严格技术重试及默认作品人工采用。T.1–T.6 已完成；应用源码 70ee657a97db05cbf50d1ebcbd29ded72ba8de2f 已推送开发分支，从完整 Git 源码构建 executor/workbench/lab 三个 latest 镜像并按 digest 上线，463 项后端组合及 105 项前端检查通过，运行源码和已登录网页已核对。T.7 保留有界真实创作及完整视听验收，技术检查不代表艺术质量提升。实验室冻结同一已发布整库完整原文为 published-release-inline 输入，正式制作保留目录、搜索和按需读取工具；启用空库与显式关闭如实记录，不回取工作 Wiki。没有新增模型请求、动画渲染、知识发布、已有默认作品替换或主线合并。详见 design 7.22。

本提案下文旧的逐方法迁移认可发布表述按其历史阶段阅读；当前唯一业务发布线仍是用户手动冻结效果库快照、自动生成校验整库 WikiSkill，不新增逐方法人工审签。采用候选、审美认可和整库发版分别留证。

用户确认以通用 Agent 的创作方法改善动画表达，并让完整效果样片、结构迁移、认可发布和正式制作形成可追溯闭环。最初复核时的固定题库、单次修订与源码优先草案属于旧基线；效果库新入口、真实续作和正式方法读取接线已经实施，后续按实际作品、发布与正式采用证据继续验收。

用户已持续授权分阶段开发、真实有界验证、完整 Git 源码构建部署；方法发布仍需开发者认可具体样片和迁移，主线合入按用户另行指示。最初“只核查和规划”的授权边界是历史阶段，不约束随后明确批准的实施。任务完成状态见 tasks.md，不从规划、代码或部署状态推断人工质量认可。

多图层表现力优化本次仅登记为后续讨论，当前先完成既定任务，不新增实施或验收范围。

## What Changes

- 2026-11-15 知识库目标确认：工作Wiki继续由Agent按真实实验经验自动积累，人工调整回到效果库；整库浏览版本仅由用户明确发版，最近五个已发布整库版本供选版阅读与版内正文全文搜索，取消知识字段人工修订。任务冻结与正式Skill发布独立，超出浏览窗口不破坏仍被引用的资料。当前先统一公共页壳及“知识库”命名，其余为design 7.21／O.x未完成任务，7.20仅保留旧阅读布局上线证据。

- 2026-11-14 资源架构讨论已收敛：实验室和正式制作共用创作能力与资源生产基础；HTML/SVG、Canvas、Three.js 随 HyperFrames 执行，Manim 等先生成资源再入同一工程。当前仅同步设计、规格与任务；已有 Manim 正式专属前置实现保持暂停，未部署或执行真实正式验证。
- 统筹先规划跨类型资源清单，旁白、音效及预制画面按依赖制作和检查；讲解段以实测旁白安排节奏，无旁白段由统筹安排。资源自身局部时间与全片放置分离，允许原预算和既定轮次内定向补做或守住明确要求的替代；共用基础先留在 video-service 内部。

- 实验室与正式制作统一使用 HyperFrames 工程、全局时间、预览定位和渲染驱动；正式交付是一个可分场景、子合成、Agent 任务与渲染块的整片工程，不只是末端转换独立动画或拼接 MP4。
- 创作知识成为版本化 SKILL.md 包，区分工程／引擎基础约定与表达方法。平台提供目录、搜索和精确读取工具，Agent 自主发现、读取、组合或不用，不由宿主固定关键词短名单代替选择。
- 外部视频网址、原观察与访问覆盖单独留研究记录。Skill 内化成独立可理解、可执行、可验证的方法；撤去原参考仍能使用，原片内容和链接不充作运行能力。
- 实验可直接改样片源码探索，但有效改进须回写候选 Skill，在代表里程碑重新生成或进行换内容、换结构的迁移验证；只修单片不算能力提升。
- 创作方法是主要复用对象，按表达问题组织；Agent提炼、维护并组合方法，工程提供运行、渲染和验证。样片源码可辅助学习与复现，不以复制源码为复用前提。
- 完整效果样片与方法独立、多对多关联。样片保留铺垫、过程、结果，默认无讲解旁白但允许必要音效，无固定8秒、单镜或首帧全显限制。
- 参考或目标先形成少量可观察标准，开发者可调整；独立评审比较完整连续样片及必要声音，重点是过程与因果。技术通过、模型评价、实际改善和人认可分别记录。
- 单次开发者委托可在显式预算内自主多轮探索；目标达成、预算耗尽或多种尝试无明显收益时停止，交付最佳结果、问题和原因；之后可继续优化，不受正片1+2约束。
- 先深入代表片段，在里程碑用少量真正不同的任务验证迁移；失败反馈到方法，回归原片和受影响案例，发布前验证与改动范围相称。
- 开发者主要看样片、比较和迁移，用自然语言反馈；Agent维护方法，详情可展开。开发者认可样片及迁移后发布确切方法版本，未发布候选不进入正式方法检索。
- 正式Agent按需实际读取、选择、组合已发布方法；记录输入和应用依据。版本冻结、无匹配自由创作、项目新效果不自动共享发布。
- 正片由Agent联合策划，一次整体确认后生成配音，以实测时长和全片上下文创作；默认一轮打磨，用户可明确追加最多两轮，之后按明确需求列表局部修改。
- 样片效果库成为实验室主入口，技术回归和日志移入内部工具或详情，旧测试作品和标注无需迁移；无用旧入口按新目标退场。
- 音效编排、真实音轨和试听进入首批闭环；Canvas／Three自由源码逐引擎准入，不新增公共渲染服务。

## Capabilities

### New Capabilities

- shared-video-resource-production: 实验室与正式制作共用的资源计划、依赖执行、生产者接口、产物身份及局部时间、失效复用、取消恢复与有界补做；不新增公共微服务，不改变各自预算／发布规则。

- reference-animation-effect-library: 方法与完整样片、多对多验证、目标评价、持续实验、迁移和开发者认可发布。
- agent-directed-video-production: 已发布方法的选择组合、联合策划、音频先行、整片上下文与真实媒体独立审阅。
- bounded-visual-revision: 仅正片的一轮自动、最多两轮用户追加与后续明确需求边界。

### Modified Capabilities

None. Existing audio-clock draft tasks share implementation and evidence through the explicit cross-references in design.md; completed historical requirements are not retroactively reinterpreted.
