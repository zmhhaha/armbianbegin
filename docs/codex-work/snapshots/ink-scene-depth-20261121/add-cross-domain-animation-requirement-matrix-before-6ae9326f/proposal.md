## Why

当前15个固定小样偏向请求/队列/执行器，同一效果在其他领域、内容结构和边界条件下缺少比较。用户要求按模块优化，并为每项能力生成一组不同领域、不同方向的需求来跑，避免只适配已有反馈。

## What Changes

- 优先增加动态图表联动、算法与数据结构、真实HTML界面操作三个表达家族，每家族至少四个数据和事件过程不同的领域需求。
- 为框图、二维过程、跨镜、Canvas和Three.js分别设计三个跨领域需求；三类新家族各四例，活动库共27例。按用户最新指示，不保留旧样例身份和历史标注，不受旧数据兼容约束。
- 每例保存受众、讲解目标、问题、实体、结论、边界、领域、引擎、复杂度及总文稿，A/B保持相同内容数据和时长。
- 提供领域/引擎筛选、需求说明和覆盖统计，以及有种子、有限范围、可冻结导出的需求评测矩阵。采集、检查和人工认可独立记录。
- 在既有独立开发者Lab发布及验收，普通用户流程不增加实验步骤。
