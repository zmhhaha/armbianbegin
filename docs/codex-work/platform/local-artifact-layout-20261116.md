# 本地开发产物

本目录统一存放这台 Windows 开发机上由 Agent 创建的临时产物、保留资料和操作记录。不要再为每轮测试在 C 盘或 D 盘根目录创建独立文件夹。

| 目录 | 用途 | 管理方式 |
| --- | --- | --- |
| `tmp/<service>/<task-id>/` | 可重建的 pytest 夹具、临时渲染和构建中间文件 | 每轮任务完成后清理；在开跑前显式指定输出路径 |
| `archives/<service>/<date>/` | 需要保留的样片、源码快照、实验结果和备份 | 保留来源映射；未经核实不当成临时文件删除 |
| `operations/<task-id>/` | 清理计划、文件校验、迁移与删除收据 | 用于复核操作；可能含私有项目数据，不整目录提交到 Git |

仓库中的源码、Git 工作树登记、Codex 聊天记录、共享运行时和生产存储继续使用各自正常位置。本次整理没有改变系统 TEMP/TMP、共享包缓存或线上服务路径。

## 后续任务
