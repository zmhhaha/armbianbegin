# 固定代码库与知识说明分别绑定

公共 Skill 提供最小入口及按需 references。它说明真实 API 的用途、参数关系、源码重建、失败反例和验证范围；不包含参考图像、私有服务数据或网络下载依赖。固定代码库由宿主供应，Skill 本身不安装代码。

学习运行时使用单文件 ink-landscape.mjs 和许可文件，记录源 Git 修订、构建工具与文件摘要。图片和视频能力在独立学习 schema 的 drawing_libraries 字段声明；源仍采用 canvas/HTML 承载及既有绝对时间接口。Agent 选择是否使用这些 API，宿主不代画作品。渲染只准入精确声明的本地文件，不开放网络或任意模块。

默认 Method 渲染及其原宿主保持原身份。视频学习使用独立宿主和受保护的静态资产/宿主路径 hook；图片使用自身已有宿主。只有学习子类允许新增资产。原 renderer image 不需包含库代码；executor 将固定资产随现有只读输入挂载传递给渲染容器。

手动发布快照加入 image-owned 库知识来源记录。既有编译器负责生成发布正文，原发布版本保持不可变；新增字段 drawing_libraries 必须经过消费兼容检查，未知/未准入正式环境不得默默加载。关闭知识时不添加本 Skill 或等同技法说明，但运行时 API 元数据和任务本身明确提供的源码不属于知识绕行。

验证分别覆盖实际源码生成、版本与摘要、API 调用、可编辑源、真实 Canvas PNG、HyperFrames 连续帧和乱序重放。技术样片不表示水墨参考相似度或用户艺术认可。生产部署只切换已验证完整 Git 构建的 executor latest 镜像；不自动发版或批量启动用户实验。

用户另授权一次真实产品实验：复用“雾退见山石”对应的原参考，在线上图片学习服务新建独立项目，保留旧项目和作品。任务明确提供固定版本的中性 API 资料，让 Agent 自行创作；该资料是本次任务输入，不伪造已发布 WikiSkill。原知识关闭选择保持，原参考像素与本次源、模型任务、实际模块/函数调用及输出分别取证。
