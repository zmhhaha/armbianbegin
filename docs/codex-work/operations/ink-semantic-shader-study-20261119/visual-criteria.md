# 水墨单帧分层 Shader 实验：视觉标准

2026-11-19。已直接查看清晰参考、528较好旧版以及r3/r4四方对照。本文件是创作前的可观察标准，不是对尚未生成作品的评分或认可。

## 五项标准

1. **山石先有体积。** 缩至约460像素宽时，中央群峰应仍读成互相压叠、大小和肩部不等的岩体，存在承担重量的连片浓墨和转折岩面。亮面应有收窄、断开或方向变化，不能从峰顶贯通山脚成为等宽浅槽；长骨脊可以局部存在，整座山不能由平行暗边/嵌套轮廓组成。远山与主峰不能仅为同一峰函数换尺度。

2. **皴擦服从岩面。** 100%山体裁切中，短皴、擦痕、墨块与少量长骨脊应有不同尺度；在岩面转折处改变方向、密度或墨量，留下不规则干笔空隙。避免从上到下均匀排丝、同长度刷毛、密集正弦长线，以及用随机颗粒覆盖来代替岩面结构。先检查黑白灰大块，再检查纹理细节。

3. **近浓远淡与留白共同建立空间。** 前景为较浓、内部仍有岩面层次的整体；主峰局部黑白对比清楚，根部逐渐隐入云；远山轻而低细节。白雾应穿插群峰根部/间隙，构成前后遮挡和呼吸空间，避免所有山同时均匀透明，或以几条同强度的白横带盖住画面。不要强制复制参考比例或水印。

4. **前景和树木不能露出生成模板。** 前景边界自然延伸至画外，不在画内垂直封口；内部不要出现重复白色砖块、等距宽槽或整片同向长拉丝。松树采用有方向和疏密差异的枝团，树干适度曲折；避免左右镜像的梳子/圣诞树和均匀针线。太阳、飞鸟只作小面积辅景，不能掩盖主体问题。

5. **Shader收益必须能局部指出。** 同一冻结源码、同尺寸、同后端比较strength=0与1，检查湿墨边缘/沉积、干笔断口、岩面亮暗和云山交界四类位置。开启后应出现有选择的湿化/墨色咬合，同时保留干笔、尖锐骨脊与空白；如果只是整体更糊、噪声更多或边缘一律摆动，不判质感提升。PNG/hash差异只证明发生改变，不是质量依据。

## 当前最重要差距

参考以连片浓墨撑住山体，再由局部断开的短皴、深浅岩面和雾化根部形成体积。528保有粗粝变化，但存在贴片/切面感；r3/r4转成高度一致的纵向长线与贯通亮槽，体积反而减弱。当前最应改变的是岩体与笔势组织，非继续给同一种峰形加模糊或噪声。

## 观察方法与边界

先并排看缩略整体，再在同一归一化位置看山体和前景100%裁切，最后看同源shader消融。比较时保留各图原始比例，不拉伸；技术通路、静态画面、连续运动、声音和用户艺术认可分别记录。任何一项未改善应如实保留，不能以“Shader/GPU已成功”补签艺术目标。
