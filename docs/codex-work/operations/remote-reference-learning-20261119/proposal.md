# 按需读取远程视频参考，统一图片与视频学习

## Why

现有视频学习必须先上传完整 MP4/WebM 并长期保存；source_url 只是备注。图片学习不能直接学习视频某一帧。参考抽帧还固定缩至 640×480，Agent 不能根据创作难点再次查看高清局部。这增加人工下载、画质损失和原片存储，限制笔触、材质和运动状态研究。

## What Changes

- 共用远程视频参考源：记录原站作品链接与实际身份，需要内容时由宿主访问原站；不提前或长期保存完整参考视频。
- 视频学习支持链接、片段与按需取帧；图片学习支持视频链接、时间点与可选局部裁剪，保留绘制源码和静态验收范围。
- Agent 可以在本次预算内请求补看帧或高清局部。宿主获取真实像素后再交给角色；不把链接、采样或工具存在冒称已观看整段或听审。
- 概览与细节采用不同观察清晰度；明示实际取得的源画质、裁剪、PTS、hash 与限制，不能把网址摘要冒充原视频 hash。
- 注册来源只保存元数据；媒体缓冲、分片和解码工作目录用后清理。实验仅保留实际观察证据和原站定位信息，生成作品、源码及方法继续正常保存。
- 保留上传来源；保持原实验重试身份、冻结证据、预算、开发者采用和手动 WikiSkill 发布规则。

## Impact

涉及 video_workbench 的参考源、媒体读取、图片/视频服务、网页与 API，以及 agent_service 的角色输入、按需观察请求和执行准入。首批适配 B 站公开可访问播放流与公开 HTTPS 直接媒体；其他站点按同一接口扩展。未准入的直播、加密或交互登录内容明确返回限制，不静默换源或降低清晰度。
