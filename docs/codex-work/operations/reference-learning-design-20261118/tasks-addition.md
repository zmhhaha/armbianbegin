## X. 需求创作、图片学习与视频学习三库（2026-11-18，设计同步，待实施）

本轮用户授权同步需求文档、OpenSpec、代码差距和实施拆分。新规则以 design.md 7.24 为准；本节不代表应用已实现、实际作品已认可或知识已发布。原105项任务的状态及证据保留，不重开、不覆盖历史完成范围；以下九项均为新增待办。

- [ ] X.1 定义三库、学习项目、实验、原参考/候选片段、内部小样、复现/迁移独立产物及关联项目的版本化契约；冻结目标、标准来源、能力/协作选择、知识绑定、反馈截止点与总预算，复用现有归属/幂等/并发/从零/重试语义，不改历史输入。
- [ ] X.2 补齐创作者与评审的真实参考/输出媒体接入：版本化角色及模型能力、图片/帧序列/适用音频运输与读取工具、实际文件/PTS/摘要/角色输入证据和有界按需上下文；旧作者v2拒图不能由reviewer vision替代，不改写冻结旧profile；材料送达不冒称理解成功。
- [ ] X.3 产品化图片学习：原图和细节、按需内部技法小样、Agent绘制源码及自制素材/生成方法、真实静帧导出、参考/较好版本/新作比较、版本保留和静态限定结论；复用HyperFrames与共用资源基础，不以内部截图或一张PNG冒充完整图片学习。
- [ ] X.4 产品化视频学习：长视频实际分析候选范围/技法/难点供用户或API方选定，已指定片段直达；按目标关键帧或直接连续片段，适用加密观察、实际音频与音画过程、参考/结果关键事件对照及真实覆盖；稀疏抽帧不写成完整观看或试听。
- [ ] X.5 扩展共同实验编排：按难点小样与自主协作、明确禁用、创作者自检及关键节点独立评审、全部角色共用预算和能力准入；冻结反馈，活动委托仅查看/停止，新意见下一实验生效，修正review与Manim实时读取_feedback路径，保留真实停止/消耗和更好版本。
- [ ] X.6 复用既有transfer角色、谱系与实质变化校验，补独立评审出题、默认复现后一次迁移、同项目分别保存两份作品；目标复现优先、预算不足迁移可未完成、无进展可提前停；分别记录画面/运动/声音/迁移范围及失败，局部和多路线结论有证据，不冒称通用；区分关闭发布整库与本次待验证方法输入。
- [ ] X.7 三库网页、外部结构化JSON API/OpenAPI及输入/证据查看同等接入：三库独立列表、项目详情聚合复现/迁移/内部尝试，可另存作品；长片候选可选、原始/有效输入及真实能力可查，运行只读停止；图片无视频参考转动画新建关联需求创作项目，现有鉴权/owner/幂等边界不绕过。
- [ ] X.8 扩展手动整库快照与自动编译校验到三库事实：图片静态技法、局部有条件知识、有效多路线及验证范围；研究资料内化且无外链运行依赖；同一发布产物浏览/搜索和正式按需消费，最近五成功整库/历史批次绑定/知识开关不回流，保留原真实发布失败，验证正式新内容实际读取与使用。
- [ ] X.9 完成合同/冻结/权限/预算/停止/恢复及UI/API集成验证，并在后续明确委托中有界实测图片、视频、适用声音、独立评审出题迁移与正式消费；分别记录技术通过、实际观察、模型结论、人工认可及知识发布。应用实施与部署另行推进，届时从完整Git源码构建实际受影响latest镜像并记录digest，不因本次文档同步勾完成。

依赖：X.1先确定公共契约；X.2与X.5、X.7界面/合同准备可并行。X.3/X.4复用X.1/X.2并接入X.5，图片与视频链路可分别推进。X.6复用已有迁移基础并接入对应真实产物；X.8可先扩快照合同，再据X.3/X.4/X.6事实验收；X.9在前述集成后执行。

归属：P.6仍承接原复杂协作实际关键画面前置检查，X.3内部小样或成片抽帧不能替代该验收；P/T的协作核心、冻结模式和知识开关、U的生产者接口、O的五版发布基础仅复用，不重复声称重新完成。R2、T.7、V.4/V.7、正式制作/音频等旧未完项保留原范围，新任务共享实际实现和证据但不代勾。正片1+2不限制三库累计实验。可信用量、费用、生产存储回收和跨服务清理继续由共享框架承接，不新增video-service重复业务待办。
